# JavaScript ES Feature Assignment — Solutions

These are the 10 separate JavaScript files for the uploaded Lec 7–10 JS ES Feature Assignment.

## Run
- Install Node.js if it is not already installed.
- Open a terminal in this folder.
- Run a file with: `node Q1_Dynamic_Data_Parser.js`
- Q6 asks for input; press Enter to use the default of 5 rows.

Each file uses `"use strict"`, prints results with `console.log()`, and includes comments/debugging notes where relevant.
