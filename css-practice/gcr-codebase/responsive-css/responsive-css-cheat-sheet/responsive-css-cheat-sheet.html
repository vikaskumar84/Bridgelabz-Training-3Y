Responsive CSS Cheat Sheet

Filters

Change the visual appearance of elements.

filter: grayscale(100%);

Media Queries

Apply styles at specific screen widths.

@media (max-width: 700px)

Responsive Design

Make layouts work on all devices.

width: 100%;

Typography

Use scalable text sizes.

font-size: clamp(1rem, 2vw, 2rem);
